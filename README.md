# Company User Database

A React-based web application to manage and view company user data.

## Live Demo
[View on CodeSandbox](https://codesandbox.io/p/github/yashhK11/IR5_MCR)

## Features

- View list of company users
- User statistics dashboard
- Detailed user profiles
- React Router navigation

```bash

cd IR5_MCR
npm install
npm start
```
